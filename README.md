# Сайт-портфолио Павла Филатова

Одностраничный сайт-визитка веб-разработчика. Свёрстан вручную на HTML5, CSS3 и
vanilla JavaScript, без конструкторов и CSS-фреймворков.

- Демо: <https://samuelglist.github.io/pavel-filatov/>
- Исходники: этот репозиторий
- Год: 2026

## Что внутри

```
index.html                 главная страница (4 раздела)
css/style.css              дизайн-система, сетка, адаптивность
js/main.js                 меню, плавная прокрутка, лайтбокс, валидация
assets/fonts/              локальные вариативные шрифты Manrope и Unbounded
assets/img/                оптимизированные изображения, QR-код
assets/icons/              SVG-иконки и favicon
demos/coffee/              лендинг кофейни «Восход»
demos/focus/               таск-борд Focus Board
demos/audit/               дашборд UX-аудита ЛК ГУАП
404.html                   страница ошибки
```

## Разделы и навигация

1. `#home` — главный экран.
2. `#about` — обо мне, навыки, подход.
3. `#work` — галерея из четырёх проектов.
4. `#contact` — контакты, QR-код и форма обратной связи.

Меню использует якорные ссылки и `scrollIntoView({ behavior: 'smooth' })`;
активный пункт подсвечивается через `IntersectionObserver`-подобную проверку
позиции секций. На мобильных меню раскрывается кнопкой-гамбургером.

## Форма

Поля: имя, email, сообщение. Валидация выполняется на клиенте:

- имя — не короче 2 символов;
- email — регулярное выражение `^[^\s@]+@[^\s@]+\.[^\s@]+$` (обязательны `@` и точка в домене);
- сообщение — не короче 10 символов.

Форма демонстрационная: данные никуда не отправляются. Для реальной отправки
достаточно подключить обработчик (Formspree, собственный endpoint) в `js/main.js`.

## Локальный запуск

```bash
python -m http.server 8123
# открыть http://127.0.0.1:8123/
```

или просто открыть `index.html` в браузере — все пути относительные.

## Публикация

### GitHub Pages

Репозиторий: `samuelglist/pavel-filatov`. Публикация из ветки `main`, каталог `/`.
После пуша сайт доступен по адресу
<https://samuelglist.github.io/pavel-filatov/>.

### Timeweb / Reg.ru / Yandex Cloud

1. Создать статический сайт или виртуальный хостинг.
2. Загрузить содержимое этой папки в корень сайта (`public_html` / `www`).
3. Включить HTTPS в панели хостинга.
4. При необходимости заменить адрес в QR-коде: `python build/make_qr.py`
   (в корне проекта) или сгенерировать QR заново для нового домена.

## Проверки

- адаптивность: 320, 360, 390, 420, 768, 1024, 1280, 1440 px;
- отсутствие горизонтальной прокрутки на всех контрольных ширинах;
- клавиатурная навигация, `skip-link`, `aria-*`, `prefers-reduced-motion`;
- форма: пустые поля, email без `@`, корректный email;
- изображения: WebP + JPEG, `srcset`/`sizes`, `loading="lazy"`;
- шрифты: локальные `.woff2`, `font-display: swap`.
